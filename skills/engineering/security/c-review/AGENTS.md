# Maintaining the portable C/C++ review

Keep the location-based review and its explicit site accounting. The bug-class catalogue supplements that pass; it does not replace reading the source. Preserve actual caller and data-flow evidence, error-path coverage, and the distinction between reviewed, unreviewed, and scope-excluded code.

Keep the portable entry point, role checklist, artifact schemas, and Python helpers consistent. A prompt is not a permissions boundary. Do not claim automated isolation, schema enforcement, independent adjudication, or measured plugin performance merely because the corresponding instructions exist.

Do not claim an accepted coverage gate when it could not run. Coverage counts concern applicable unit/question/site checks, not correctness. Preserve part files and expected counts; never reconstruct missing findings from a truncated summary.
