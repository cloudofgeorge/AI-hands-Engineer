# Marketing

Growth, positioning, acquisition, conversion, lifecycle, and revenue skills for software products.

This README is a routing index for agents. Keep it short; detailed procedures belong in each linked `SKILL.md`.

## How to choose

- Prefer the narrowest skill that directly matches the task.
- Load additional skills only when their workflow is needed, not just because the topic is adjacent.
- Use research and strategy skills before writing copy when positioning, audience, or channel is unclear.
- Use conversion skills for a specific page, form, signup, paywall, or funnel problem.
- Use lifecycle and revenue skills when the work continues after signup: email, SMS, referrals, churn, RevOps, or sales enablement.
